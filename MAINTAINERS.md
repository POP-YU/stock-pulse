# Maintainers

## Current maintainer

- **@POP-YU** — repository owner and primary maintainer.

## Responsibilities

The primary maintainer owns the ongoing maintenance loop for StockPulse:

- issue triage and prioritization;
- pull request review and merge decisions;
- release preparation and changelog maintenance;
- security-report coordination;
- CI and repository automation health;
- documentation accuracy;
- roadmap review and scope control.

## Maintenance cadence

The project aims for a lightweight but visible maintenance cadence:

- **weekly:** review new issues, pull requests, CI failures, and user-reported breakage;
- **monthly:** review roadmap, changelog, dependencies used by GitHub Actions, documentation drift, and release readiness;
- **quarterly:** review security posture, architecture assumptions, upstream data-provider risks, and governance documentation.

These are maintenance targets rather than guaranteed service-level commitments.

## Transparency

Maintenance work should leave useful public history where appropriate: real fixes should use pull requests or focused commits, release-worthy changes should be recorded in `CHANGELOG.md`, and user-impacting decisions should be explained in issues or pull requests. Artificial activity, fabricated usage metrics, or synthetic community engagement should not be created for appearance.
